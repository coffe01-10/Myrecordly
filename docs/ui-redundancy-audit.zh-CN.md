# HeroUI 编辑器冗余审计

于 2026 年 9 月 19 日在 `recordly-heroui` 重新设计期间审查。结论基于当前渲染进程和源码，包括现有的未提交重新设计工作。

## 已清理

| 区域 | 问题 | 改动 |
| --- | --- | --- |
| 缩放检查器 | 同一个选中块有两个 Delete Zoom 按钮：一个在滚动内容中，另一个在固定页脚中。 | 保留固定页脚的操作。 |
| 扩展导航 | 一个常驻工具标签只导向"Extensions are no longer available."。 | 移除了该导航项；保留了现有的兼容组件。 |
| 账户导航 | 一个常驻按钮只显示"Account coming soon."。 | 移除了该占位按钮。 |
| 片段和字幕检查器 | 面板标题被紧接着重复为区块标题，却没有引入子区块。 | 保留面板标题，移除了重复的标题。 |
| 基础缩放检查器 | Animation 标题、Reset 按钮和指向 Settings 的提示在没有动画控件的情况下出现。实际控件仅存在于 Advanced 中。 | 将这些与 Classic Animation 一起归入 Advanced。 |

## 进一步的整合机会

这些是建议，而非本补丁中的额外改动。

1. **裁剪有两个独立的编辑入口。** 工具栏会打开可视的 Crop Video 对话框；Scene → Advanced 为同一裁剪状态提供四个内嵌滑块。将精确的内嵌输入和重置放入裁剪对话框，使裁剪编辑只有一个地方。整合时请保持数值精度。
2. **缩放控件分散在两个检查器中。** 块检查器包含 Mode、Amount 和 Classic Animation；Settings 包含 Connect neighboring zooms、自动建议和 Motion Presets。将运动设置归入一个标签清晰的项目级子区块，与 Zoom 控件并列，而不是用一条把用户引向别处的提示。某些运动预设也会影响光标，因此其作用范围必须保持明确。
3. **添加内容被拆分到 Add Layer 和相邻按钮。** Add Layer 提供注释/音频，而 Add Zoom 是独立的图标。单一 Add 菜单可以枚举所有受支持的插入操作；将 Split 作为编辑操作保持独立。悬停添加是实用的直接操作方式，无需移除。
4. **支持类命令占用了常驻的编辑工具栏空间。** Discord 和 Feedback 位于打开项目和 Undo/Redo 旁边。单一的 Help 菜单可以同时容纳它们以及快捷键帮助。这是优先级较低的工具栏杂乱问题，而非两个完全相同的功能。
5. **音频重复了它的检查器标题。** Audio 检查器内部的"Audio"标题主要是为 Reset 提供一个归属。在标准化区块操作时，将 Reset 移到检查器头部。
6. **Saved Presets 和 Motion Presets 需要更清晰的作用范围。** 头部存储整个编辑器的预设；Settings 应用运动预设。它们是不同的功能，但重复的命名模糊了这一区别。将前者标注为"Style presets"，将后者标注为"Motion"，或说明各自的作用范围。

移除了未使用的兼容时间线工具栏及其设计目录 fixture，以及未挂载的 TimelineAxis 和 ClipMarkerOverlay 组件。移除了被忽略的 SliderControl props 及其调用点取值。

## 已修复的交互缺陷

- 将 `handleClipDelete` 连接到 `TimelineEditor.onClipDelete`。此前 Backspace 到达的是一个空操作，因为该回调缺失。
- 在时间线焦点检查之前，为每种选中的块类型一致地路由 Delete、Backspace 和配置的删除快捷键。检查某个块不再使其无法删除。表单控件、可编辑文本、组合事件和叠加控件保留各自的键盘行为。
- 移除了仅针对片段的 Backspace 特例，它绕过了共享的选择优先级。
- 当播放头离开某字幕片段的时距时，保留该选中的字幕片段。删除仍会将片段映射到其源字幕 cue。
- 移除了对片段、注释和音频删除中可选选择回调的不必要要求。
- 在选择时间线块时清除过期的关键帧选择。
- 在导航到全局侧边栏工具时清除块选择。此前选中的注释会覆盖每个工具的检查器，使 Cursor、Scene、Webcam 和 Settings 看起来显示相同的内容。

## 验证

通过：TypeScript 检查、72 个聚焦单元测试、14 个浏览器测试、定向 lint 和 diff 空白检查。

回归覆盖包括每种块类型的键盘删除、检查器删除、片段撤销、seek 后的字幕删除、文本输入保护和从注释检查器切换离开。单元覆盖包括两个删除键、配置的快捷键、选择优先级、可编辑/叠加守卫，以及组合/修饰键处理。浏览器测试使用真实渲染进程，配合模拟的 Electron 桥接和 fixture 媒体；此处未对打包后的 Electron 进行测试。

## 视频库和 HUD 后续工作

- HUD 的源/设备行以及源/区域触发器使用 ghost 按钮。项目卡片适配 300px 的 HUD 弹窗，可纵向滚动并带细滚动条，且不再将库截断在 24 个条目。 
- 当源未改变时，字幕生成会跳过会话重新注册，从而保留已激活的伴随音频批准。本地媒体 URL 会解析当前服务器端口；预览会通过现有的已批准媒体 API 重试一次失败的本地加载。
- Videos 在最左侧使用一个次级头部按钮，并用轻量文件卡片（无内嵌视频播放器）替换现有的左侧检查器。它列出配置的录制目录中的文件。移除操作会通过文件系统移动来暂存选中的录制及其捕获伴随文件。Undo 会恢复最近一次移除，而不复制媒体或覆盖更新的文件；下一次移除或应用退出会将暂存文件送入系统回收站。这取代了早先仅隐藏的行为。自动的录制时长/数量清理已被移除。
- 时间线拖放会在片段边界处插入。由于预览/导出共享单一源，导入会在 `.recordly-media` 中准备一个不可变的合并源。新素材会适配当前源画布/帧率；后续导入会复制已准备好的现有视频，并带有无损的系统/麦克风伴随文件和偏移后的光标遥测数据。大型录制的准备需要时间。片段源边界可防止裁剪进下一段录制。时间线历史可以撤销/重做插入，因为现有源偏移被保留。
- 现有的 FFmpeg 元数据解析器现在由导入和导出共用，而不是重复一份，或依赖此开发安装中发现的、不兼容的 FFprobe 二进制文件。

验证：真实的 FFmpeg 集成覆盖不同尺寸、音频路由、重复插入和原始文件保留。浏览器测试覆盖库移除/撤销、拖拽插入/撤销/重做、无需会话重置的字幕生成、预览恢复，以及 HUD 弹窗中的 30 个项目。1x/2x/4x 下的字幕可见性和间隙吸附仍被覆盖。


## 片段、叠加层和云集成

- Videos 检查器使用共享的搜索、复选框、菜单和按钮控件。文件行支持选择、双击/+ 插入，以及拖动到时间线；批量 Trash 位于操作菜单中。不加载任何库视频元素。
- 摄像头导入会规范化并拼接一条独立的摄像头轨道，考虑捕获起始偏移，并保留源时间可见范围。预览和两条渲染路径都会在纯屏幕区间隐藏气泡。已保存的项目会保留这些范围；样式预设会省略它们，并在应用时保留当前源的范围。
- 导入的点击、鼠标抬起、右键点击和光标形状样本会保留事件类型、偏移后的时间戳，以及经过信箱调整的坐标。
- 注释拖动边界现在使用完整画布。位置百分比可以延伸到录制矩形之外，并在保存/重新加载后保留；导出使用相同的坐标。摄像头和字幕叠加层已经使用各自的画布布局。
- 缩放块在空间允许时显示图标和完整标签；窄块隐藏图标和模式，同时保留数值倍数。
- 云集成已从 cloud worktree 移植，包括其当前的服务/查看器编辑、桌面身份验证、分片上传，以及为分享准备当前编辑结果。Account 位于工具栏底部；Create share link 位于 Export 中。没有任何内容被部署或上传。实时登录需要 authentication.md 中所述的公共 Supabase 环境设置。


缩略图和登录打磨：Videos 使用惰性请求的 160×90 JPEG 静帧，按源路径、修改时间和大小进行缓存。它显示未修改的文件名（含扩展名），带省略号和完整的悬停标题。登录使用 HeroUI 的 Modal、Form、TextField、Input、Button 和 Alert 组件，并共享样式。
